# 🎮 GTA Cheats Hub

Uma aplicação web moderna desenvolvida para reunir, organizar e facilitar a busca de **cheats (códigos/macetes)** de todos os jogos da franquia **Grand Theft Auto (GTA)** em diferentes plataformas.

---

## 📌 Sobre o Projeto

O **GTA Cheats Hub** é um catálogo interativo feito para jogadores que querem consultar trapaças e códigos de qualquer edição do GTA de forma rápida, intuitiva e responsiva.

O frontend é desenvolvido com **Next.js**, aproveitando recursos modernos de renderização, performance e componentização.

## ✨ Funcionalidades Planejadas

- 🔍 **Filtro e Busca em Tempo Real:** Pesquise por efeito do cheat, categoria (armas, veículos, saúde, clima, procurado, etc.) ou jogo.
- 🎮 **Seleção de Plataforma:** Alterne facilmente entre PC, PlayStation, Xbox, Switch e Mobile para ver os botões ou códigos correspondentes.
- 📋 **Copiar com 1 Clique:** Copie comandos de console ou códigos numéricos de celular diretamente para a área de transferência.
- 📱 **Design Responsivo:** Interface otimizada tanto para desktop quanto para smartphones (ideal para consultar enquanto joga).
- ⭐ **Favoritos:** Salve seus cheats favoritos localmente no navegador.

## 🛠️ Como Executar o Projeto

### Pré-requisitos

- Node.js (versão 18.x ou superior recomendada)
- Gerenciador de pacotes (`npm`, `pnpm` ou `yarn`)

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/vitor-comits/gta-cheats-frontend.git
   cd gta-cheats-frontend
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra no navegador:
   ```
   http://localhost:3000
   ```
